# realm-entrance

The separate home for The Realm's first-person 3D entrance.

- [Terra build plan](BUILD_PLAN.md): proposed prototype, batches and review gates.
- [Project status](context/project.md): current evidence and source context.
- [Handover](HANDOVER.md): newest work first.

The first desktop visual study is available locally. Run `npm install` and `npm run dev`, then open the local address printed by Vite. Use WASD and mouse, Escape to pause, and R to reset. This is a visual prototype: the artifact and passage do not yet respond, and mobile is not supported.
